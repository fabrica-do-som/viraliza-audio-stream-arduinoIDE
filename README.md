# viraliza-audio-stream-arduinoIDE
Firmware para conexão Wi-Fi e reprodução de streaming por interface I2S, com conversor digital-analógico PCM5102 na plataforma ArduinoIDE. Foram feitas inicialmente 2 versões, uma delas permite a conexão de AP no ESP32, enquanto a outra conecta na rede com as credenciais inseridas diretamente no código (hardcoded).
